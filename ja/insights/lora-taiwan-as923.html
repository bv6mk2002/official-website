LoRa の周波数はどう選ぶ？AS923 と SF・BW の設計ポイント

台湾と日本の LoRa は 920MHz 帯（AS923）を使用します。周波数、拡散率（SF）、帯域幅（BW）と、通信距離・電池寿命のトレードオフを整理しました。

目次
  1. 1. どの周波数帯を使うべきか
  2. 2. 拡散率（SF）：距離と速度のトレードオフ
  3. 3. 帯域幅（BW）とパケット長
  4. 4. 通信距離を最も左右するのはアンテナと設置場所
  5. 5. ポイント・ツー・ポイントか LoRaWAN か

LoRa はごく少ない電力で数 km の通信ができるため、広域センシングで人気の技術です。しかし同じ SX12xx チップでも、設定次第で通信距離、データ量、電池寿命が何倍も変わります。ここでは、よくいただくご質問をまとめました。

1. どの周波数帯を使うべきか

LoRa は免許不要の小電力無線で、国・地域によって使える周波数が異なります：

地域主なチャネルプラン周波数帯
台湾AS923920〜925MHz
日本AS923920MHz 帯
米国、カナダUS915902〜928MHz
欧州EU868863〜870MHz
中国本土CN470470〜510MHz

台湾で販売する製品は 920〜925MHz を使い、NCC の低出力無線規格（LP0002）に適合する必要があります。日本では電波法に基づく技術基準適合証明（技適）が必要で、キャリアセンスなどの要件もあります。複数の市場で販売する場合は、ハードウェア設計の初期段階で周波数帯を決めておきましょう。アンテナと整合回路は周波数ごとに設計するため、周波数が変わると部品の定数や、場合によってはアンテナ自体の変更が必要になります。

2. 拡散率（SF）：距離と速度のトレードオフ

LoRa の SF は通常 SF7〜SF12 です。SF が 1 上がるごとに、1シンボルあたりの時間は約2倍になります：

  • SF が高い：受信感度が上がり通信距離が延びますが、送信時間（Time on Air）が長くなり消費電力も増えます。
  • SF が低い：高速・省電力で通信容量も大きくなりますが、距離は短くなります。

実務では、まず現地で通信エリア試験を行い、「必要十分」な SF を選びます。一律に SF12 にするのはおすすめしません。同じデータを SF12 で送ると SF7 の数十倍の送信時間がかかり、電池寿命とチャネルの混雑が大きく悪化します。

3. 帯域幅（BW）とパケット長

よく使われる帯域幅は 125kHz です。帯域幅が狭いほど感度は上がりますが速度は遅くなり、広いほどその逆です。また、パケットはできるだけ短くしましょう。センサー値のバイナリ化、変化分のみの送信、複数データのまとめ送りなどで送信時間を大きく短縮できます。

設計のヒント：まず「どのくらいの頻度で、1回に何バイト送るか」を決めてから、SF、BW、電池容量を逆算しましょう。データの設計は、チップ選定以上に電池寿命を左右することがあります。

4. 通信距離を最も左右するのはアンテナと設置場所

同じ設定でも、アンテナの整合が悪かったり金属ボックス内に設置したりすると、距離が大幅に落ちます。主なポイントは次のとおりです：

  • ゲートウェイのアンテナはできるだけ高く、金属の遮蔽物から離して設置する。
  • ノードのアンテナは、基板単体ではなく実際の筐体に入れた状態で測定・整合調整する。
  • 電池、金属ネジ、LCD などもアンテナの周波数ずれの原因になる。

アンテナ設計については、別記事「PCB アンテナの選び方：IFA・メアンダ・パッチと整合調整」もご覧ください。

5. ポイント・ツー・ポイントか LoRaWAN か

ノード数が少なく構成がシンプルな案件では、独自のポイント・ツー・ポイント（P2P）通信が早く安く開発できます。ノード数が多い、複数ゲートウェイ間のローミングが必要、公衆ネットワークに接続したい、といった場合は、標準規格の LoRaWAN のほうが拡張や保守が容易です。プロジェクトの規模と長期的な運用を考慮して、最適な構成をご提案します。
