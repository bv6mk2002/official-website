PCB アンテナの選び方：IFA・メアンダ・パッチと整合調整

PCB アンテナは低コストで組立も不要ですが、基板スペースや周辺部品の影響を強く受けます。代表的な PCB アンテナの特徴と、ネットワークアナライザによる整合の方法を解説します。

目次
  1. 1. 代表的な PCB アンテナの種類
  2. 2. レイアウトの注意点
  3. 3. ネットワークアナライザで整合を取る
  4. 4. 外付けアンテナやモジュールを選ぶべきケース

多くの IoT 製品が PCB アンテナを採用しています。基板上に直接パターンを描くため、追加部品も組立も不要でコストが最も低くなります。一方で、基板サイズ、グラウンド、筐体の影響を最も受けやすいため、設計には注意が必要です。

1. 代表的な PCB アンテナの種類

種類特徴適した用途
モノポール最もシンプルな構造。長さは約 1/4 波長で帯域が広い基板スペースに余裕がある場合
IFA（逆 F アンテナ）モノポールを折り曲げ短絡点を加えた形。小型で整合しやすい2.4GHz の Wi-Fi／BLE で最も一般的
メアンダパターンを蛇行させて全長を短縮。効率と帯域は低下するサブギガ帯（LoRa など）でスペースが限られる場合
パッチ指向性があり利得が高い。しっかりしたグラウンド面が必要指向性通信、GPS、高い周波数帯

周波数が低いほどアンテナは大きくなります。920MHz では 1/4 波長が約 8cm になるため、小型製品ではメアンダ設計や外付けアンテナが必要になることが多くあります。

2. レイアウトの注意点

  • クリアランス（キープアウト）：アンテナの下や周囲は、すべての層で銅箔もパターンも配置しない。最も多いミスです。
  • グラウンド面の大きさ：モノポール系のアンテナはグラウンド面を片側の素子として利用します。グラウンド面が小さすぎると周波数や効率がずれます。
  • 配置：アンテナは基板の端に置き、電池、LCD、金属筐体、高速デジタル信号から離します。
  • 整合回路を用意しておく：給電点に π 型整合回路（部品3個分）のパッドを用意します。初版は 0Ω 抵抗だけでも、後から調整できる余地を残せます。

3. ネットワークアナライザで整合を取る

アンテナ設計の最後の工程は実機での調整です。ネットワークアナライザで S11（反射係数）を測定し、目標の周波数帯で十分に整合が取れているかを確認します：

  • 一般的な目安は S11 が −10dB 以下（VSWR 約2以下）です。
  • まず共振周波数の位置を確認し、高すぎる・低すぎる場合は整合回路のインダクタやコンデンサの値で補正します。
  • 必ず「完成品の状態」で測定してください。筐体や電池を取り付け、手で持った状態も再現しなければ、参考になるデータは得られません。

4. 外付けアンテナやモジュールを選ぶべきケース

金属筐体の製品、長距離通信が必要な製品、またはスケジュールに余裕がなく認証のリスクを避けたい場合は、実績のある外付けアンテナやアンテナ内蔵モジュールのほうが結果的に有利なことがよくあります。製品の条件に合わせて最適な方法をご提案します。

既存製品の受信不良でお困りですか？製品全体を再設計することなく、アンテナの診断と整合調整をスポットでお受けします。お問い合わせ
