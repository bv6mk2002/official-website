台灣 LoRa 頻段怎麼選？AS923 與 SF、BW 參數設計重點

LoRa 在台灣使用 920–925 MHz（AS923）。本文整理頻段、擴頻因子（SF）、頻寬（BW）與傳輸距離、電池壽命之間的取捨。

本文目錄

  2. 二、SF（擴頻因子）：距離與速度的取捨
  3. 三、BW（頻寬）與封包長度
  4. 四、影響距離最大的其實是天線與安裝位置
  5. 五、點對點還是 LoRaWAN？

LoRa 能以極低功耗傳送數公里，是廣域感測的熱門選擇。但同樣一顆 SX12xx 晶片，參數設定不同，傳輸距離、資料量與電池壽命可能差上數倍。以下整理我們在專案中最常被問到的幾個問題。

一、台灣該用哪個頻段？

LoRa 屬於免執照的低功率射頻，各國開放頻段不同：

地區常見頻率規劃頻段
台灣AS923920–925 MHz
美國、加拿大US915902–928 MHz
歐洲EU868863–870 MHz
中國大陸CN470470–510 MHz

在台灣銷售的產品應使用 920–925 MHz，並符合 NCC《低功率射頻器材技術規範》（LP0002）。若產品同時要外銷，建議在硬體設計初期就規劃好頻段，因為天線與匹配電路是依頻率設計的，不同頻段往往需要不同的元件值，甚至不同的天線。

二、SF（擴頻因子）：距離與速度的取捨

LoRa 的 SF 通常介於 SF7 到 SF12。SF 每增加 1，每個符號的傳輸時間約增加一倍：

  • SF 越高：接收靈敏度越好、距離越遠，但空中傳輸時間（Time on Air）越長、越耗電。
  • SF 越低：傳輸快、省電、通道容量大，但距離較短。

實務上，我們會先在現場做覆蓋測試，找出「剛好足夠」的 SF，而不是一律設成 SF12。用 SF12 傳送同樣的資料，空中時間可能是 SF7 的數十倍，電池壽命與通道壅塞都會明顯惡化。

三、BW（頻寬）與封包長度

常用頻寬為 125 kHz。頻寬越窄，靈敏度越好但速度越慢；頻寬越寬則反之。另外，封包越短越好：把感測值以二進位壓縮、只傳變化量、合併多筆資料再送，都能有效縮短空中時間。

設計建議：先決定「多久回報一次、每次幾個位元組」，再回推 SF、BW 與電池容量。資料規劃往往比晶片選型更影響電池壽命。

四、影響距離最大的其實是天線與安裝位置

同樣的參數，天線匹配不佳或安裝在金屬箱內，距離可能只剩一小段。幾個常見原則：

  • 閘道器天線盡量架高，避開金屬遮蔽物。
  • 節點天線需在實際外殼內量測、調校匹配，而不是只看裸板數據。
  • 電池、金屬螺絲、LCD 等元件都可能讓天線頻率偏移。

關於天線設計，可以參考我們另一篇文章〈PCB 天線怎麼選？IFA、Meander、Patch 與匹配調校〉。

五、點對點還是 LoRaWAN？

節點數少、架構單純的案子，點對點（P2P）私有協定開發快、成本低；節點數多、需要多閘道器漫遊、或要接入公用網路時，LoRaWAN 標準協定較容易擴充與維護。我們會依專案規模與長期維運需求，建議合適的架構。
